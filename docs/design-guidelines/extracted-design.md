# ForkLens visual direction

The supplied logo uses deep ink navy (`#071536`), midnight violet (`#171b4d`), electric cyan (`#4ee8f6`), mint (`#35efae`), coral (`#ff596d`) and cool periwinkle (`#8f97cf`) on an icy near-white field. Rounded code panels, connected graph nodes, diff lines and a magnifying glass communicate comparison and verification.

The product UI translates this into a dense code-review workstation rather than a card-based landing page: a persistent top command bar, left release graph, central split diff, right provenance rail and bottom verdict console. Monospaced labels, fine grid lines and sharp status color distinguish it from prior project dashboards. The logo remains a compact brand mark, not a repeated hero illustration.
